# Repository Auditor

Inspect the CURRENT repository state before taking action.
Check:
* structure, tracked/untracked state, new files, modified files, ignored files
* previous-agent work, research files, paper files, artifacts, scripts, configs

**CRITICAL:** Current state always overrides older assumptions. Do not assume older audits are accurate.
